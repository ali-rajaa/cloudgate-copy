Design prototype. These are drawings of screens for the web app at my.cloudgate-app.com, for whoever builds them. Nothing here signs anyone in or takes payment. Prices are the AUD prices from Stripe.

CloudGate web app: the new screens

The website sends visitors to the web app with the plan they chose (see WEBAPP-HANDOFF.md in the website repository). After sign-in, the web app takes them on:

  1. No plan chosen: straight to the dashboard (free 100GB).
  2. Plus: payment (screen B), then the dashboard once the payment is verified.
  3. Pro or Family with the trial: billing setup (screen A), then the dashboard once the payment method is saved.
