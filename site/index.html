Features

Everything a cloud storage app should do.

Every feature below is included in the free 100GB plan. No add-ons, and nothing held back for a paid tier.

Swipe to explore

Photo cloud storage

Every photo and video you take is copied to your account automatically. Photo cloud storage and video cloud storage in the same account, kept at original quality rather than shrunken copies.

One-tap restore

Switching phones or need it all back? Restore your library to a new device in one action. Because your files sit in online file storage, moving between Android and iPhone is a sign-in rather than a migration.

Secure cloud storage

Files are encrypted in transit, and Vault Lock adds a passcode layer to the folders you choose. Each one covers a different risk.

Document scanning

Scan receipts, IDs and paperwork straight into your account. Online file storage that handles documents as easily as photos, organised so you can find them later.

Multi device cloud storage

Cross platform cloud storage across Android, iOS and web from one account. Access files anywhere, on any device, without emailing anything to yourself.

File and folder sharing

Share a file or a whole folder with anyone, whether or not they use CloudGate. Full quality originals rather than the compressed copies messaging apps send.
